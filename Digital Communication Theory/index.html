Digital Communication Theory

Dive deeper into the fundamental concepts of digital communication systems. Explore signal representations, modulation techniques, and channel effects that form the backbone of modern communication technologies.

Binary and M-ary Signals

Binary Signals

Binary signals use two distinct symbols to represent digital information, typically 0 and 1. These are the fundamental building blocks of digital communication systems.

Types of Binary Signals:

  • Unipolar: Uses 0 and +V volts
  • Polar: Uses -V and +V volts
  • Bipolar: Uses -V, 0, and +V volts (AMI encoding)

M-ary Signals

M-ary signaling uses M > 2 distinct symbols to transmit multiple bits per symbol, increasing spectral efficiency.

Key Concepts:

  • Symbol Rate: Rs = Rb/log₂(M)
  • Bits per Symbol: log₂(M)
  • Examples: 4-PAM, 8-PSK, 16-QAM
  • Advantage: Higher data rate in limited bandwidth

PCM Formats & Line Codes

Pulse Code Modulation (PCM)

PCM is a method used to digitally represent sampled analog signals. It's the standard form of digital audio in computers, CDs, and digital telephony.

1. Sampling

Convert continuous signal to discrete-time samples at Nyquist rate

2. Quantization

Map samples to finite set of amplitude levels

3. Encoding

Represent quantized values as binary codewords

Line Codes

Line codes are techniques for representing digital data as a sequence of voltage or current pulses for transmission over a physical medium.

Line Code Description Advantages
NRZ (Non-Return to Zero) Signal doesn't return to zero between bits Simple, efficient bandwidth usage
RZ (Return to Zero) Signal returns to zero in middle of bit period Self-clocking, easy synchronization
Manchester Transition in middle of each bit period No DC component, self-clocking
AMI (Alternate Mark Inversion) Binary 1s alternate in polarity No DC, error detection

Power Spectral Density (PSD) of Line Codes

The Power Spectral Density describes how the power of a signal is distributed over frequency. Different line codes have different PSD characteristics:

NRZ PSD

Has significant DC component and main lobe bandwidth of Rb

P(f) = Tb sinc²(πfTb)

Manchester PSD

No DC component, main lobe bandwidth of 2Rb

P(f) = Tb sin²(πfTb/2) / (πfTb/2)²

Geometric Representation of Signals

Signal Space Representation

Any set of M finite-energy signals {si(t)} can be represented as linear combinations of N ≤ M orthonormal basis functions {φj(t)}.

Signal Representation:

si(t) = Σj=1N sij φj(t)

where sij are the signal coefficients

Key Properties:

  • Energy: Ei = Σ sij²
  • Distance: dij = ||si - sj||
  • Inner Product: ⟨si, sj⟩ = Σ siksjk

Constellation Diagrams

A constellation diagram is a representation of a signal modulated by a digital modulation scheme in the complex plane, showing the signal as a collection of points.

Common Constellations:

BPSK: 2 points on real axis
QPSK: 4 points at ±45°, ±135°
16-QAM: 4×4 grid in I-Q plane
8-PSK: 8 points equally spaced on circle

Orthogonal Symbols & Gram-Schmidt Orthogonalization

Orthogonal Signals

Two signals s1(t) and s2(t) are orthogonal if their inner product is zero:

⟨s1(t), s2(t)⟩ = ∫ s1(t)s2(t)dt = 0

Properties of Orthogonal Signals

  • No mutual interference
  • Optimal for signal separation
  • Minimize error probability
  • Maximum Euclidean distance

Examples

  • sin(ωct) and cos(ωct)
  • Walsh functions
  • Orthogonal frequency carriers (OFDM)
  • Spreading codes (CDMA)

Gram-Schmidt Orthogonalization Process

The Gram-Schmidt process is a method for orthonormalizing a set of vectors in an inner product space. It's fundamental in constructing orthonormal basis functions for signal representation.

Algorithm Steps:

  1. Initialize: φ1(t) = s1(t) / ||s1(t)||
  2. For each signal si(t):
    • Project si(t) onto existing basis functions
    • Subtract projections: vi(t) = si(t) - Σ⟨si, φj⟩φj(t)
    • Normalize: φi(t) = vi(t) / ||vi(t)||
  3. Result: Orthonormal basis set {φ1(t), φ2(t), ..., φN(t)}

Baseband Signal Transmission through Bandlimited Channels

Intersymbol Interference (ISI)

ISI occurs when a pulse spreads beyond its allocated time slot, causing it to interfere with neighboring pulses. This is a major impairment in digital communication systems.

Causes of ISI

  • Bandlimited channels
  • Multipath propagation
  • Non-ideal filters
  • Timing errors

Effects of ISI

  • Increased bit error rate (BER)
  • Reduced data rate
  • Performance degradation
  • Detection errors

Mathematical Representation

y(t) = Σ akh(t - kT) + n(t)

Sampled at t = nT: yn = anh0 + Σk≠n akhn-k + nn

Where the second term represents ISI

Receiver Output in the Presence of ISI

The received signal at the sampler output contains the desired symbol plus interference from other symbols:

rk = ak + Σi≠k aih(kT - iT) + nk

Desired Signal
ISI Term
Noise

Zero ISI: Nyquist Criterion

Zero ISI can be achieved if the overall channel-pulse response satisfies the Nyquist criterion for zero ISI:

Nyquist First Criterion

h(nT) = { 1, n = 0; 0, n ≠ 0 }

The pulse response must be 1 at the sampling instant and 0 at all other sampling instants

Raised Cosine Filter

Most popular pulse shape satisfying Nyquist criterion:

  • Roll-off factor α (0 ≤ α ≤ 1)
  • Bandwidth: B = (1+α)/(2T)
  • Zero ISI at sampling instants
  • Practical implementation

Equalization Techniques

Methods to combat ISI:

  • Zero-forcing equalizer
  • MMSE (Minimum Mean Square Error)
  • Decision feedback equalizer (DFE)
  • Adaptive equalization

Controlled ISI: Partial Response Signaling

Instead of eliminating ISI completely, controlled ISI introduces a known amount of interference to achieve higher data rates or better spectral efficiency.

Duobinary (Class 1)

h(t) = p(t) + p(t-T)

  • 3 levels: -2, 0, +2
  • Bandwidth: R/2
  • Spectral efficiency: 2 bits/s/Hz

Modified Duobinary

h(t) = p(t) - p(t-2T)

  • 3 levels: -2, 0, +2
  • No DC component
  • Better for AC-coupled channels

Advantages

  • Reduced bandwidth
  • Better spectral efficiency
  • Tolerant to timing jitter
  • Simple implementation

Precoding for Partial Response

To avoid error propagation in detection, precoding is used before partial response shaping:

dk = ak ⊕ dk-1 (for duobinary)

Where ⊕ represents modulo-2 addition
